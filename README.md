# Barcode Syrup — промо-сайт

Одностраничный сайт натуральных сиропов Barcode Syrup (Кыргызстан, 33 вкуса).
Вся графика сделана кодом: 3D-бутылка на Three.js, SVG и canvas.

## Что внутри

- Загрузка: штрихкод со сканирующей лазерной полосой.
- Первый экран: стеклянная 3D-бутылка с жидкостью, пузырьками и этикеткой. При скролле она вращается, а жидкость, фон и этикетка меняются по вкусам: манго, клубника, мохито, карамель, маракуйя.
- Lenis (плавный скролл) и GSAP ScrollTrigger: заголовки собираются по буквам, фон плавно перетекает между секциями.
- Каталог 33 вкусов с фильтром. Карточки приподнимаются, наклоняются и светятся цветом вкуса, у каждой есть кнопка заказа в WhatsApp.
- Рецепты: сироп «наливается» в стакан при прокрутке.
- Цены, блок для кофеен и баров, контакты, WhatsApp +996 507 508 636. На телефоне кнопка закреплена внизу экрана.
- Без WebGL показывается запасная SVG-бутылка. При `prefers-reduced-motion` движение минимальное.

## Запуск

Сайт статический, сборка не нужна. Библиотеки лежат в `vendor/`.
Из-за ES-модулей открывать нужно через локальный сервер:

```bash
python3 -m http.server 8000
# http://localhost:8000
```

Для публикации подойдут Netlify, Vercel или GitHub Pages: достаточно загрузить папку целиком.

## Файлы

- `index.html` — разметка
- `css/style.css` — стили и адаптив
- `js/data.js` — вкусы, рецепты, телефон
- `js/scene.js` — 3D-сцена (Three.js)
- `js/main.js` — скролл, анимации, сборка секций
